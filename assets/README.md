# Open Sensei artwork

`open-sensei-icon.png` is the original app artwork generated for this project with OpenAI's built-in image generation tool. It has transparent corners and is distributed with the project under the MIT license. It contains no third-party brand marks.

The build converts this checked-in PNG to the standard macOS icon sizes using ImageIO and `iconutil`. No AI service is required at build time.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for Open Sensei, a lightweight, local Mac system and battery monitor. Create ONE polished, original icon, front-facing and perfectly square 1024x1024. A dark forest-green rounded-square macOS tile with subtle dimensional edge lighting, centered with generous transparent space around the rounded corners. Inside, a bold mint-green open circular gauge incorporates one simple flowing pulse stroke, suggesting calm system awareness, energy efficiency, and the O in Open. Strong simple silhouette readable at 32px. Restrained premium native macOS look, smooth precise curves, very subtle soft shading, crisp edges. No lettering, no numbers, no wordmark, no tiny tick marks, no Apple logo, no screenshots, no additional objects, no mockup background. Preserve actual transparent alpha outside the icon tile. This is an original identity, not a copy of any existing app logo.
